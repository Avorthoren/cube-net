# Changelog

What's new in every version of Cube Net. While working, write the changes under "Unreleased"; a release
(`./release.sh 1.2.0`) gives that section its version and date, and its text becomes the release's notes.

## Unreleased
 - "View" menu added
 - Achieved area goal indication improved on the instruments panel 

## 2.0.0 (2026-11-22)
 - **The ability to work with a limited set of other bodies added**
 - Cut lines can go outside the net now
 - Coordinates numerators and denominators limited to 2100 decimal digits
 - "Center" button added
 - Emergency project restoration implemented (for cases when application bug damaged the project)
 - Crash|error reports added
 - Performance of dragging significantly improved (relevant for smaller color tilings)
 - Faces and dashes colorings settings can now be not whole numbers
 - Coordinates inputs improved: denominator is set to 1 when numerator is edited
 - Style settings are not global but per project now
 - Application remembers zoom, working sheet position and window size now
 - File path added to footer

## 1.2.0 (2026-11-15)
 - Exact value of bounding rectangle area added to the hint
 - Hint found bounding rectangle vertices added
 - Help opens by itself at the first start
 - Language selector added to Help page
 - Color picker added in Settings
 - Bug with "Place Vertex" feature not allowing to end the cut fixed

## 1.1.0 (2026-11-15)
 - "Place vertex" feature implemented
 - "Set slope" feature implemented
 - "Show vertex coordinates" setting added
 - "Move the origin" feature implemented
 - "Help → Help" section lists all hotkeys now
 - Hotkey (L) for vertex labels added
 - Focus-off for target area input improved
 - Default edge thickness → 4 px, default vertex radius → 6 px
 - Shift+click no longer deletes a vertex (Ctrl+click does)
 - Release notes indentation fixed

## 1.0.0 (2026-11-13)
 - Instruments panel buttons style improved
 - Dialog/notification windows refined

## 0.1.0 (2026-11-12)
Initial release
