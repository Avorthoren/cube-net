# Changelog

What's new in every version of Cube Net. While working, write the changes under "Unreleased"; a release
(`./release.sh 1.2.0`) gives that section its version and date, and its text becomes the release's notes.

## Unreleased
 - "Place vertex" feature implemented
 - "Set slope" feature implemented
 - "Show vertex coordinates" setting added
 - "Move the origin" feature implemented
 - "Help → Help" section lists all hotkeys now
 - Hotkey (L) for vertex labels added
 - Focus-off for target area input improved
 - Default edge thickness → 4 px, default vertex radius → 6 px
 - Shift+click no longer deletes a vertex (Ctrl+click does)
 - Release notes indentation fixed

## 1.0.0 (2026-11-13)
 - Instruments panel buttons style improved
 - Dialog/notification windows refined
